# 如何打开本目录 / How to open this folder

Study 4 can be opened in either of these folders:

1. **[`../Study4/`](../Study4/)** — complete package (article, figures, Word, IJCM files, numbered data). Start with [`../Study4/README.md`](../Study4/README.md).
2. **[`../Study4_Global_AI_Civil_Engineering_Economy/`](../Study4_Global_AI_Civil_Engineering_Economy/)** — same openable copy under the original folder name.
3. **This folder** (`Study4_FINAL_VERSION/`) — working copy (code, extra experiments, data).

Cursor cannot preview zip files (*binary file is not supported*). Open [`00_OPEN_IN_EDITOR.md`](00_OPEN_IN_EDITOR.md) and [`FIGURES.md`](FIGURES.md).

| Folder / file | What it is |
|---|---|
| `data/` | Official downloads and analysis panels (Eurostat TNLG, SBS M71, BaTIS, ILO, APS copies). No fabricated cells. |
| `tables/` | All CSV tables from those series |
| `figures/` | Figures 1–23 (PNG), generated by the scripts from `data/` |
| `FIGURES.md` | Markdown gallery of figures 1–23 (open this, not the PNGs/zip) |
| `manuscript/` | English article + Chinese article (figures linked so they render when you open the markdown) |
| `scripts/` | Replication code. `ROOT/data` is this folder’s `data/`. |
| `00_previous_ijcm_data/` | Previous occupation-paper files (instruments only; LLM scores are **not** the shock) |
| `zips/` | Download-only zip backups (do not open in the IDE) |
| `results.json`, `results_nlg.json`, `results_industry.json` | Machine-readable estimates written by the scripts |
| `EXPERIMENTS_RUN.md` | Log of the experiment scripts that produced tables and figures |

Regenerate everything from the CSVs in `data/` and rebuild the complete zip:

```bash
cd Study4_FINAL_VERSION
python3 scripts/run_all_experiments.py
```
